# 豆包输入法图标仓库

这是一个给豆包输入法使用的图片直链收藏页，分为：

- 动态图标：10 个 GIF
- 静态图标：2 个 PNG
- 默认图标：1 个 PNG

打开页面后，点击卡片或“复制直链”按钮，即可复制图片的 Raw 直链。当前仓库地址为：

https://raw.githubusercontent.com/agarcabin/doubao-ime-icons/main

在线页面：

https://logo.agar-cabin.site/

## 本地预览

直接打开 index.html 即可查看；如果浏览器限制本地文件的剪切板权限，可在此目录启动任意静态文件服务器后再打开页面。
